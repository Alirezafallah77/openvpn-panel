رکورد A دامنه را به IPv4 همین سرور متصل و TCP 80 و 443 را در فایروال میزبان باز کنید. رکورد AAAA اشتباه را حذف کنید. دامنه را بدون https://، مسیر یا پورت وارد کنید. صدور و تمدید گواهی با Caddy خودکار است؛ گواهی وب با گواهی خصوصی اتصال OpenVPN متفاوت است.

تا تأیید گواهی، تنظیمات ورود پنل تغییر نمی‌کند. بعد از موفقیت، آدرس HTTPS جدید را باز و دوباره وارد شوید. یک دامنهٔ HTTPS قبلی هنگام تغییر حفظ می‌شود. در خطا، تنظیمات پیشین بازگردانده می‌شود؛ قطع برق و خطای دیسک ممکن است نیاز به بازیابی از SSH داشته باشد.

اگر یک دامنه برای VPN و پنل استفاده می‌کنید، در Cloudflare آن را DNS only قرار دهید. پروکسی معمولی HTTP/CDN ترافیک خام OpenVPN را عبور نمی‌دهد.

OpenVPN Protocol (UDP / TCP)

پروتکل فعلی: {{ settings.protocol|upper }} • پورت: {{ settings.port }} • آدرس فایل‌های جدید: {{ settings.endpoint }}

این نسخه هم‌زمان فقط یک پروتکل دارد. پورت ثابت فعلی حفظ می‌شود؛ برای TCP، TCP همین پورت (پیش‌فرض 1194) را در فایروال شرکت میزبان باز کنید و برای UDP، UDP همان پورت را. پورت 443 مربوط به HTTPS پنل است. تغییر پروتکل، مصرف/اعتبار یا گواهی کاربران را پاک نمی‌کند.

دانلودهای قبلی خودکار تغییر نمی‌کنند. بعد از تغییر آدرس یا پروتکل، فایل .ovpn تازه بگیرید؛ یا اگر فقط IP سرور عوض شده، رکورد همان دامنهٔ VPN را منتقل کنید. UDP معمولاً انتخاب اول است؛ TCP برای شبکه‌هایی که UDP را مسدود کرده‌اند کاربرد دارد.
