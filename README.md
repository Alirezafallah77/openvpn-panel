# OpenVPN Panel — هستهٔ اولیه، در حال توسعه

این مخزن در وضعیت **آزمایشی و ناقص** است. هنوز پنل وب، نصب‌کننده، تولید پیکربندی و گواهی OpenVPN، لینک اشتراک قابل استفاده و اتصال به سرور OpenVPN ندارد. همچنین هیچ اتصال VPN را قطع یا از ورود جلوگیری نمی‌کند؛ برای استفاده عملی یا روی سرور عمومی مناسب نیست.

## هدف نسخهٔ نخست

- اوبونتو 24.04 و نصب جدید OpenVPN روی یک سرور.
- مدیریت کاربران، سهمیهٔ مجموع دریافت و ارسال، و اعتبار از اولین اتصال موفق.
- نمایش مصرف و باقی‌مانده از طریق لینک محرمانهٔ اختصاصی.
- جلوگیری از اتصال و قطع اتصال فعال در پایان سهمیه یا اعتبار.

## آنچه اکنون پیاده‌سازی شده

هستهٔ مستقل پایتون و SQLite برای ساخت کاربران، توکن تصادفی و ذخیرهٔ هش آن، شروع اعتبار با اولین اتصال، حسابداری مجموع شمارنده‌های تجمعی هر نشست، غیرفعال‌سازی دستی، و محاسبهٔ وضعیت. تراکنش‌ها به‌منظور جلوگیری از دوباره‌شماری و تضاد بین نشست‌ها استفاده می‌شوند. این هسته فقط داده‌هایی را محاسبه می‌کند که یک اتصال‌دهندهٔ قابل اعتماد در اختیارش بگذارد؛ به‌تنهایی هیچ محدودیتی بر ترافیک اعمال نمی‌کند.

## اجرای آزمون‌ها

روی Python 3.10 یا جدیدتر، بدون وابستگی خارجی:

```bash
python3 -m unittest discover -s tests -v
```

## کارهای ضروری پیش از انتشار

1. اتصال مطمئن به OpenVPN برای ثبت شروع/پایان نشست و شمارنده‌ها، و بازیابی پس از راه‌اندازی مجدد؛ آزمون عملی شامل قطع ناگهانی و هم‌زمانی نشست‌ها.
2. قطع نشست‌های فعال پس از اتمام اعتبار یا حجم، از جمله هنگام نبود رویداد جدید؛ تعیین فاصلهٔ نمونه‌برداری و میزان تجاوز احتمالی. طراحی fail-closed در هنگام خرابی بخش حسابداری.
3. صدور، ابطال و گردش گواهی، تولید فایل کلاینت و تنظیم شبکه و فایروال با حداقل دسترسی لازم.
4. پنل وب با احراز هویت امن مدیر، حفاظت CSRF، محدودیت نرخ، TLS، نشست امن و ثبت رویداد بدون ذخیرهٔ اسرار در لاگ.
5. صفحهٔ اشتراک فقط‌خواندنی، عدم درج توکن در لاگ و امکان چرخش/ابطال توکن. لینک اشتراک اطلاعات خصوصی است.
6. نصب‌کننده و ارتقا، پشتیبان‌گیری و بازیابی امن، مهاجرت پایگاه داده، و آزمون سرتاسری روی اوبونتو 24.04.
